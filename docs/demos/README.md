# Demo Video Assets

Place walkthrough recordings and media demonstrations in this directory.

Recommended files:
- `main_demo.mp4`: Complete end-to-end user workflow demonstration.
- `onboarding_demo.mp4`: Clinical intake, triage questionnaire, and persona selection.
- `detection_demo.mp4`: Real-time disfluency and phonological process analysis (English & Urdu).
- `practice_demo.mp4`: Interactive exercise formats (Minimal Pairs, Bombardment, Carrier Phrases, etc.).
- `techniques_demo.mp4`: Fluency shaping, stuttering modification, and DAF session execution.
