# Demonstration Video Catalog

This directory contains standalone video recordings illustrating key functional modules of the Clario platform.

## Available Recordings

- `english.mov` (23.8 MB): English Disfluency & Phonological Screening. Covers paragraph acoustic screening and standard sentence-level assessment, showing word-level alignment, disfluency scoring, and SODA phoneme error breakdown.
- `urdu.mp4` (20.6 MB): Urdu Multilingual Diagnostic Assessment. Showcases native Urdu phonological assessment with localized clinical prompts, audio capture, and bilingual model evaluation.
- `practice.mp4` (13.9 MB): Personalized Exercise Generation & Practice. Demonstrates dynamic curriculum synthesis (AMLM, AEG, Gemini LLM) with targeted minimal pairs, carrier phrases, and drill exercises.
- `techniques.mp4` (33.7 MB): Clinical Techniques & Real-Time Biofeedback. Highlights evidence-based stuttering modification and fluency shaping techniques, Silero VAD repair detection, syllable-rate measurement, and Delayed Auditory Feedback (DAF).
- `progress.mp4` (4.5 MB): Longitudinal Analytics & Gamification Dashboard. Displays patient session history, longitudinal accuracy tracking, streaks, and motivation mechanisms.
